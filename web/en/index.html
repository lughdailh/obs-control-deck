Free software · No extra hardware

Botonera is a native OBS Studio plugin. It brings your chosen scenes, DSK graphics and transitions together in one visual dock. Set it up your way, then switch to production mode.

Built to work inside OBSUniversal macOS · Windows x64

Features

The controls you need.
Where you expect them.

You don’t have to include every scene. Pick the ones you use and give each button an image, a label and a shortcut.

▦

Your own grid

Choose columns and rows. Set the size or let the buttons fit the available space, always square.

↧

An image. One gesture.

Drop an image onto a button. It becomes part of the deck without preparing its dimensions.

⌨

Use your keyboard too

Assign a shortcut to each button. Configuration mode shows the combinations you have set.

◉

Preview and program at a glance

A steady warm light for program, a pulse for preview, and red and green frames. The number is always there.

⇄

Transitions within reach

Pick a type, duration or preset. Then press TRANSICIÓ to send preview to program.

▣

Configure. Then produce.

Drag to reorder, right-click to edit, then enter production mode to protect the layout.

Workflow

Set it up first.
Then run the show.

  1. 01

    Open the deck

    In OBS, go to Docks → Botonera and place it where it suits you.

  2. 02

    Make it yours

    Choose the grid, assign scenes and DSK graphics, then add images and shortcuts. Drag to reorder.

  3. 03

    Enter production mode

    Use the right-click menu to switch from configuration to production and protect the buttons.

  4. 04

    Prepare, then take to program

    In studio mode, select your preview scene. Pick a transition and duration, or a preset, then press TRANSICIÓ.

Downstream Keyer

Graphic on.
Graphic off.

A button for your logo, guest lower third or scoreboard. One click shows it, the next hides it, using the effect configured in Downstream Keyer.

  • Graphics act directly on the output.
  • Each DSK channel keeps one composition selected.
  • Choose a different composition on the same channel to replace the previous one.

Requires Downstream Keyer by Exeldro. Botonera controls its selection; it doesn’t replace the plugin.

Before you start

Do I need a hardware control deck?

No. It is a grid of buttons inside OBS, controlled with your mouse or keyboard shortcuts. The machine in the icon is the project illustration.

What exactly does a preset do?

It stores a transition type and duration. Pressing it prepares those values; you then press TRANSICIÓ to run the change. A preset does not take preview to program by itself.

Is the configuration saved?

Yes. The grid, buttons, images and shortcuts are saved with your scene collection. You can also export and import the deck with embedded images.

Can I edit during a recording?

When recording or streaming starts, the deck enters production mode. You can then manually return to configuration to make a change.

What do the DSK buttons need?

Downstream Keyer must be installed, with compositions added to its channels. If TIE is active, Botonera blocks that channel’s action. DSK is independent of preview and the main transition.
